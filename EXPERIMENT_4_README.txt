EXPERIMENT 4 - FOOD DELIVERY WEBSITE

AIM:
To create a food delivery website where users can order food from a particular restaurant listed in the website.

ALGORITHM:
1. Create two HTML pages – restaurant list and restaurant menu/cart.
2. Add CSS for cards, images, buttons and modals.
3. Store restaurant and menu data in JavaScript.
4. Display restaurants with a View Menu button.
5. Open the selected restaurant menu.
6. Display menu items with images and prices.
7. Add selected items to the cart.
8. Place the order and show confirmation.
9. Confirm the order and display a success message.

FILES:
- index.html
- restaurant.html
- foodapp.css
- foodapp_data.js
- foodapp_script.js
- experiment4_all_in_one.html
- images/ (the 5 supplied food images)

RUN:
Open index.html in a browser. Click View Menu, add food to cart, and place the order.

RESULT:
The Food Delivery web application was successfully created and executed using HTML, CSS and JavaScript with food images.
